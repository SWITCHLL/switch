# Event Creation Wizard - User Guide

## Overview
The Event Creation Wizard guides you through creating an event in 5 simple steps. Each step focuses on a specific aspect of your event, making it easier to organize your information.

## Step-by-Step Walkthrough

### Step 1: Event Details
**What you'll enter:**
- **Event Title** (required) — Name of your event (e.g., "Afrobeats Live Concert Lagos")
- **Description** — Tell attendees what to expect (optional, up to 5000 characters)
- **Category** — Choose the event type (concerts, conferences, sports, etc.)
- **Seating Type** — How seats are organized:
  - General Admission (open seating, first-come-first-served)
  - Reserved Seating (assigned seats)
  - Mixed (some sections general, some reserved)

**Tips:**
- Write a compelling title that's easy to search for
- Use the description to highlight key attractions or unique features
- Choose the seating type that matches your event format

### Step 2: Event Type & Dates
**What you'll enter:**
- **Start Date & Time** (required) — When does your event begin?
- **End Date & Time** (optional) — When does it end?
- **Free Event** — Toggle if all tickets are free
- **Virtual / Online** — Toggle if attendees join remotely
- **Stream/Meeting URL** (if virtual) — Link to Zoom, YouTube Live, etc.

**Tips:**
- Set accurate times so attendees know when to arrive
- If you're unsure of end time, you can leave it blank
- Virtual events: paste your meeting link (must start with https://)
- The end time must be after the start time

### Step 3: Event Location
**For In-Person Events:**
- **Venue Name** — Name of the venue (e.g., "Victoria Island Convention Center")
- **Address** — Street address (optional)
- **City** — Which city? (required)
- **State/Region** — State or region
- **Capacity** — How many people can attend? (optional, leave blank for unlimited)

**For Virtual Events:**
You'll see a note that venue isn't needed, as attendees will join via your meeting link.

**Tips:**
- Venue name helps attendees find your location
- City is required for searching and filtering
- Capacity helps with ticket type planning

### Step 4: Sales Window
**What you'll enter:**
- **Sales Open** (optional) — When can people start buying tickets?
- **Sales Close** (optional) — When do ticket sales end?

**Tips:**
- Leave blank if you want tickets available until the event
- Sales must open before your event starts
- Sales close date must be after sales open date
- Consider closing sales a few days before the event for logistics

### Step 5: Event Images
**What you'll do:**
- Upload up to 6 images for your event
- Drag & drop or click to browse
- Set the first image as your event banner (marked as "Primary")
- Remove unwanted images

**Accepted formats:** JPEG, PNG, WebP, GIF (max 8 MB each)

**Tips:**
- First image (Primary) shows as the event banner on listings
- Upload a mix: poster, venue interior, performers, crowd scenes
- High-quality images increase ticket sales
- You can reorder images by clicking "Set as primary"

## Preview Screen

After completing all steps, you'll see a **Preview Screen** showing:
- Event banner image
- All event details formatted nicely
- Image gallery
- Summary of what you entered

**On this screen:**
- Review everything before creating
- Click **Edit** to go back and change anything
- Click **Create Event** to finalize

## Mobile Experience

### Progress Indicator (Mobile Only)
Shows "Step X of 5" and the current step name with a progress bar.

### Button Layout
- **Mobile:** Buttons stack vertically, Back/Next in easy-to-tap arrangement
- **Desktop:** Buttons side-by-side for quick navigation

### Input Fields
- Full-width on mobile for easy typing
- Organized in grids on larger screens

## Validation & Error Handling

### What Triggers Errors?
- Missing required fields (marked with *)
- Invalid dates (end before start)
- Invalid URLs (must include https://)
- Field length limits exceeded
- Missing venue info for in-person events

### How to Fix
- Error messages appear in red below each field
- Simply correct the information and continue
- Error dismisses automatically when you fix it

## After Creating Your Event

Once you submit, you'll be redirected to your **Event Dashboard** where you can:
- Add ticket types and pricing
- Configure seating/seat maps
- Add speakers or performers
- Upload more images
- Publish your event
- Manage bookings and attendees

## FAQ

**Q: Can I save as draft?**
A: Yes! Create your event and it saves as a draft. You can edit it anytime before publishing.

**Q: Can I change details after creating?**
A: Yes! You can edit all details on the Event Dashboard until you publish.

**Q: Do I need to add images?**
A: No, images are optional. But they help attract attendees!

**Q: What if I make a mistake?**
A: Click **Edit** on the preview screen or go back to your Event Dashboard to edit later.

**Q: Can I create events on mobile?**
A: Yes! The wizard is fully mobile-optimized for creating events on your phone.

## Keyboard Navigation

- **Tab** — Move between fields
- **Shift + Tab** — Move back between fields
- **Enter** — On buttons or toggles, activate them
- **Spacebar** — On toggles, flip them on/off

## Accessibility

- All form fields are properly labeled
- Error messages associated with inputs
- Color not used alone to convey information
- High contrast for better readability
- Works with screen readers
